# Code style

- Do not add comments to project source code.
- Express intent through descriptive names, explicit types, and small, focused functions.
- Keep the README minimal.

# Model files

STL files are generated by `bun run model` from `src/model.ts` and committed under `public/models/`. Each opening variant has its own directory:

| Opening    | Directory                  |
| ---------- | -------------------------- |
| `top`      | `public/models/`           |
| `diagonal` | `public/models/diagonal/`  |

Each directory contains:

- `orbital-planter.stl`: printable planter body
- `orbital-saucer.stl`: printable saucer
- `orbital-section.stl`: cutaway mesh for the viewer, not for printing
- `orbital-planter.zip`: the two printable STLs bundled for download
- `specification.json`: dimensions, groove layout, opening profile, and per-part triangle counts, volumes, and bounds in millimetres

`modelAssetPath(opening, filename)` in `src/model.ts` resolves these paths. Without a checkout, fetch them from `https://raw.githubusercontent.com/wu-json/orbital-planter/main/public/models/<variant path>`.

After changing the model geometry, run `bun run model` to regenerate every variant and commit the updated files.
